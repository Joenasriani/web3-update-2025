# Legacy 4D Tesseract Prototype

This repository is **not a Web3 publication or 2025 Web3 update** despite its legacy repository name.

The current contents are an interactive browser prototype for visualizing a four-dimensional hypercube (tesseract) through 3D projection and six 4D rotation planes.
